# Milestone 3 – Employee Wellness Management Analytics

## Features Implemented

### Daily Wellness Journal
- Users can write journal entries.
- AI analyzes emotions and sentiment.
- Journal entries are saved to the database.

### Journal Analysis
- Detects language.
- Detects emotion.
- Calculates confidence score.
- Displays positive, neutral, negative and compound sentiment scores.
- Shows emotion distribution chart.

### Wellness Recommendation
- Gives personalized wellness suggestions based on sentiment score.
- Positive mood → Encouragement.
- Neutral mood → Self-care suggestions.
- Negative mood → Stress relief recommendations.

### Upload Journal File
- Upload TXT or CSV journal files.
- AI analyzes uploaded content.

### Journal History
- Displays previous journal entries.
- Shows detected mood, date and confidence score.

## Technologies Used
- Python
- Streamlit
- FastAPI
- PostgreSQL (Neon)
- NLP
- Matplotlib
